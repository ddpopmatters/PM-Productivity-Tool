## Requirements

### 1. Database Migration

Create `supabase/migrations/033_website_sitemap.sql`:

```sql
-- Website Sitemap Planner
-- Adds: website_sitemap_nodes (self-referencing tree, max 3 levels enforced in app)

CREATE TABLE IF NOT EXISTS website_sitemap_nodes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  project_id UUID NOT NULL REFERENCES website_project(id) ON DELETE CASCADE,
  parent_id UUID REFERENCES website_sitemap_nodes(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  slug TEXT,
  page_type TEXT NOT NULL DEFAULT 'content'
    CHECK (page_type IN ('content', 'form', 'redirect', 'external')),
  status TEXT NOT NULL DEFAULT 'planned'
    CHECK (status IN ('planned', 'in_progress', 'live')),
  sort_order INTEGER NOT NULL DEFAULT 0,
  linked_page_id UUID REFERENCES website_pages(id) ON DELETE SET NULL,
  notes TEXT,
  created_by_email TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX IF NOT EXISTS idx_sitemap_nodes_project ON website_sitemap_nodes(project_id);
CREATE INDEX IF NOT EXISTS idx_sitemap_nodes_parent ON website_sitemap_nodes(parent_id);
CREATE INDEX IF NOT EXISTS idx_sitemap_nodes_order ON website_sitemap_nodes(project_id, parent_id, sort_order ASC);

DROP TRIGGER IF EXISTS trg_website_sitemap_nodes_updated ON website_sitemap_nodes;
CREATE TRIGGER trg_website_sitemap_nodes_updated
  BEFORE UPDATE ON website_sitemap_nodes
  FOR EACH ROW EXECUTE FUNCTION update_website_updated_at();

ALTER TABLE website_sitemap_nodes ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Authenticated users can read website_sitemap_nodes"
  ON website_sitemap_nodes FOR SELECT TO authenticated USING (true);
CREATE POLICY "Authenticated users can insert website_sitemap_nodes"
  ON website_sitemap_nodes FOR INSERT TO authenticated WITH CHECK (true);
CREATE POLICY "Authenticated users can update website_sitemap_nodes"
  ON website_sitemap_nodes FOR UPDATE TO authenticated USING (true);
CREATE POLICY "Authenticated users can delete website_sitemap_nodes"
  ON website_sitemap_nodes FOR DELETE TO authenticated USING (true);
```

### 4. New Component: `SitemapView.jsx`

Props: `{ sitemapNodes, pages, isAdminUser, userEmail, handlers }`

#### Layout

Header row:
- Title "Sitemap" + node count badge
- "Import from Pages" button (admin only) — imports all pages as sitemap nodes (skips if sitemap already has nodes; show confirmation if nodes exist: "This will add pages not yet in the sitemap")
- "Add top-level page" button (admin only)

#### Tree rendering

Build the tree client-side from the flat `sitemapNodes` array:
1. Root nodes: `parent_id === null`, sorted by `sort_order`
2. Level-1 children: `parent_id === rootNode.id`, sorted by `sort_order`
3. Level-2 children: `parent_id === level1Node.id`, sorted by `sort_order`
4. Enforce max depth: do not render or allow creation of level-3 children (nodes whose parent is already a level-2 node)

#### Node row

Each node renders as a row with:

```
[indent] [status dot] [name — inline editable] [slug — inline editable] [type badge] [linked page badge] [actions]
```

- **Indent**: Level 0 = no indent, Level 1 = `pl-6`, Level 2 = `pl-12`
- **Status dot** (8px circle): planned=`bg-graystone-400`, in_progress=`bg-amber-400`, live=`bg-green-500`
- **Name**: Click to edit inline (input replaces text, blur/Enter saves, Escape cancels)
- **Slug**: Shown as `text-graystone-500 text-xs` next to name. Click to edit inline.
- **Page type badge**: content=`bg-ocean-100 text-ocean-700`, form=`bg-sky-100 text-sky-700`, redirect=`bg-graystone-100 text-graystone-600`, external=`bg-purple-100 text-purple-700`
- **Linked page badge**: If `linked_page_id` is set, show the page name as a small `bg-green-100 text-green-700` badge. Clicking it opens a dropdown to change/clear the link.
- **Actions** (show on row hover):
  - "Add child" icon button (+ icon) — only if current level < 2. Inserts a new blank child node immediately below.
  - Edit icon button — expands an inline edit panel below the row (see below)
  - Delete icon button — confirm then delete (if node has children, warn: "This will also delete N child pages")

#### Inline edit panel

Expands below the node row (same indentation), `bg-graystone-50 border-t border-graystone-100 px-4 py-3`:
- Page type select (content / form / redirect / external)
- Status select (planned / in_progress / live)
- Linked page select — dropdown of `pages` (from PageInventory), shows page name + section, clears with "None"
- Notes textarea
- Save / Cancel buttons

#### "Add top-level page" / "Add child" flow

Inserts a new node row in edit mode (blank name input focused) at the correct position. On save, calls `handleCreateSitemapNode`. On cancel, removes the temporary row.

#### Empty state

"No sitemap yet — add your first top-level page or import from the Page Inventory."

#### Import from Pages behaviour

- Calls `handleImportPagesAsSitemapNodes(pages)` — passes all current `pages`
- Each page becomes a root-level sitemap node with `linked_page_id` set, `name` = page name, `slug` = page slug, `status` = 'planned'
- If `sitemapNodes.length > 0`, show inline confirmation: "Add [N] pages from inventory as sitemap nodes?" with confirm/cancel

## Design Constraints

- **Tab bar style**: same underline pattern as existing tabs — `border-b-2 border-ocean-600 text-ocean-900` active, `text-graystone-600 hover:text-graystone-800` inactive
- **Status dots**: 8px circles (`w-2 h-2 rounded-full`) — same pattern as PageInventory
- **Inline edit**: name/slug edit triggered by click; input replaces text in-place, no modal
- **Tree lines**: optional subtle left border on child groups (`border-l-2 border-graystone-100 ml-3`) to show hierarchy visually
- **Node count badge**: `bg-graystone-100 text-graystone-600 text-xs px-2 py-0.5 rounded-full`
- **Hover actions**: `opacity-0 group-hover:opacity-100 transition-opacity` pattern — don't clutter rows

## Acceptance Criteria

1. Migration `033_website_sitemap.sql` exists with table, indexes, trigger, RLS.
2. `fetchSitemapNodes` returns all nodes for a project ordered by `sort_order`.
3. `deleteSitemapNode` removes a node; DB cascade removes its children.
4. `SitemapView` builds a 3-level tree from flat array (root → child → grandchild).
5. Clicking a node name edits it inline; blur/Enter saves; Escape cancels.
6. "Add child" button is hidden on level-2 nodes (max depth enforced).
7. Linked page badge shows page name resolved from `pages` prop (not the UUID).
8. "Import from Pages" button creates one sitemap node per page with `linked_page_id` set.
9. BuildView has a "Sitemap" tab between Pages and Templates.
10. OngoingView has a "Sitemap" tab between Launch Readiness and Templates.
11. `npm run build` exits 0 with no errors.
